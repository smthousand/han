# WONSUKHAN

index.html 하나로 된 사이트. 빌드 없이 그대로 올리면 된다 (파일을 직접 열어도 동작).

- works.js  작품 목록과 식별 정보 (「작품 정리」 문서 기준)
            id 가 있는 작품만 상세가 열린다. 없는 작품은 목록에 회색으로 나온다.
            사진은 img 폴더에 넣고 img: ['파일명.jpg'] 로 적는다.
- texts.js  작품 설명과 인용문 (국문). 작품 id 로 연결된다.
- data.js   전시 목록 · 약력 · 연락처
- img/bg5.png  배경 패턴 / img/logo.svg  로고
